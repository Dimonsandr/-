# Правила проекта

- Работать только внутри папки smeta.
- Сохранять готовые функции и проверять расчёты после изменений.
- Использовать HTML, CSS и JavaScript без npm, зависимостей и сервера.
- Не отправлять данные сметы в сеть.
- Поддерживать телефон, клавиатуру и печать А4.
- После каждой законченной функции выполнять проверку и отдельный коммит.
