Создано приложение «Смета за 5 минут» на HTML, CSS и JavaScript без сервера и npm.
Добавлены расчёт, скидка, НДС, валюты, печать А4, черновик и копирование текста для WhatsApp.
Собственная функция — каталог услуг; контрольный итог 37 620 подтверждён браузерной проверкой.
Функции сохранены отдельными коммитами, выполнен учебный откат через git revert.
Загрузка на GitHub, GitHub Pages и отметка присутствия пока не выполнены: нужен доступ к аккаунтам; ссылка на репозиторий появится после push.
