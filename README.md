# Смета за 5 минут

Откройте index.html в современном браузере. Установка, npm и сервер не нужны.

## Возможности

- Реквизиты, номер и сегодняшняя дата.
- Добавление и удаление позиций, Enter создаёт новую строку.
- Количество × цена, скидка и НДС от суммы после скидки.
- Валюты KZT, RUB, USD, EUR. Выбор меняет обозначение, без конвертации.
- Сохранить PDF: откроется печать браузера. Выберите «Сохранить как PDF», А4, отключите колонтитулы браузера. Короткая смета помещается на одну страницу, длинная продолжается на следующих.
- Черновик сохраняется в localStorage этого браузера. Очистка данных браузера удалит его; в приватном режиме сохранение может быть недоступно.
- Копирование текста для WhatsApp. Приложение само ничего не отправляет. Если буфер недоступен, появится выделяемый текст.
- Собственная функция: каталог из трёх услуг с редактируемыми ценами.

Проект не использует внешние библиотеки, аналитику и сетевые запросы. Данные сметы не входят в репозиторий.

## Проверка по уроку

2 × 15 000 + 1 × 8 000 = 38 000. Скидка 10% = 3 800, после скидки 34 200. НДС 10% = 3 420. Итого 37 620.

Проверены в Edge: поля, расчёт, удаление, фокус новой строки, Enter, пустые поля, скрытие нулевых строк, валюты, каталог, текст мессенджера, вызов печати, восстановление черновика после перезагрузки. Печать вручную и фактическое получение PDF пользователем не проверялись.

## GitHub

Публикация ещё не выполнена: требуется подключение аккаунта. После создания пустого публичного репозитория smeta без README и лицензии:

    git remote add origin https://github.com/ВАШ_ЛОГИН/smeta.git
    git push -u origin main

Не вводите ВАШ_ЛОГИН буквально: подставьте свой логин. Затем Settings → Pages → Deploy from a branch → main → / (root) → Save. Адрес выдаст GitHub после публикации.
